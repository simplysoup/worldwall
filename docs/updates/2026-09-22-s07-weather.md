## Bounded outcome

Added a provider-neutral weather boundary that can be wired to one approved provider later without making the selector or renderer network-aware. Disabled weather creates no worker and no request. Enabled fake-provider work runs on a dedicated worker, permits at most one request in flight, enforces a minimum fifteen-minute poll interval, uses bounded retry delays, normalizes finite Celsius/precipitation/timestamp data, and exposes cache freshness/error state.

The cache is a versioned bounded key/value record written through a same-directory temporary file and atomic rename. Cache directories/files are restricted to the user on Unix. Corrupt, unsupported, future-invalid, or oversized records are rejected by the cache loader; the service retains its in-memory value on provider failures. The service has no selector handle: completion increments a cache epoch and updates the weather snapshot only.
