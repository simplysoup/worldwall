## Outcome

Added `OpenMeteoProvider` behind the existing worker-backed `WeatherProvider`
seam. It uses the documented HTTPS `/v1/forecast` endpoint and requests only
current Celsius temperature, precipitation in millimetres, WMO weather code,
and a Unix timestamp with GMT timezone. It maps WMO codes into Worldwall's
normalized weather conditions, converts positive precipitation to the Boolean
field, rejects malformed/oversized/non-finite responses, and maps timeout,
authorization, rate-limit, and network failures without exposing the request
coordinates in ordinary error messages.

The provider uses `reqwest` blocking + Rustls inside the existing dedicated
worker; it does not run on the Wayland/event thread. `WeatherConfig::open_meteo`
selects the fixed `open-meteo.com` source while preserving disabled-by-default
behavior and the existing 15-minute/bounded-retry policy.
