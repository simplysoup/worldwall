## Implemented slice

- Added `src/ipc.rs`, a version-1, big-endian length-prefixed JSON protocol
  with 4 KiB request and 16 KiB response limits, two-second command deadlines,
  bounded client/queue counts, same-user peer credentials, mode-0600 socket
  setup, safe runtime-directory/path checks, stale-socket handling, and
  double-start rejection.
- Added `src/bin/worldwallctl.rs` with all six command forms: `status`,
  `reload`, `reload-config`, `scene ID`, `next`, and `weather`.
- IPC worker threads only parse/framing and wait for a response. Commands are
  delivered through a bounded calloop channel and applied by the existing
  multi-output event-loop owner.
- Added `src/config.rs` with schema-versioned `fps`/`registry_dir` parsing,
  complete registry/fallback validation, bounded input, regular-file checks,
  and candidate-before-commit behavior. `reload-config` changes no scene and
  rejects invalid candidates without replacing the old config.
- Wired explicit IPC selection commands through `SelectionController` and the
  existing `SceneTransaction`/shared-renderer swap boundary. `weather` reports
  cache state only; it never starts a provider request. Status excludes exact
  location and credentials.
- Added [IPC and configuration reference](../ipc.md) and CLI/config guidance
  to the README.

## Follow-up implementation and live verification

IPC diagnostic limiter and corrected registry-path transitions. A validated
transition to another registry replaces only future selection input; a
transition to `registry_dir = "none"` keeps the resident transaction/scene for
status while returning `selection_unavailable` for future selection commands.
A later validated registry can be installed without an implicit selection.
