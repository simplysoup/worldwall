## Approval and bounded outcome

`simplysoup` approved CR-0002 for implementation on 2026-09-22. The increment
adds the smallest optional scene resource: a contained `time_of_day.toml`, a
256×N opaque RGBA8 atlas, and ordered civil-second keyframes. The loader rejects
malformed, uncontained, non-opaque, out-of-range, duplicate-time, and
insufficient timelines before GPU allocation. Existing packages without the
field keep the one-palette path.

The renderer uploads the atlas and keyframes once with the scene. Each frame
writes the existing bounded animation uniform with monotonic animation seconds,
explicit civil seconds, keyframe count, and an enabled flag. WGSL performs
row selection, 86,400-second wrap, authored-byte interpolation with a floor,
then the existing sRGB/linear and animation-effect path. The clock value never
enters scene selection. The runtime accepts only an explicit
`WORLDWALL_UTC_OFFSET_MINUTES`; it does not infer the host timezone.
