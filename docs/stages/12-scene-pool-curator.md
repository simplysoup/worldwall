# S12 — Local scene-pool curator and automatic eligibility

## Purpose

Deliver the approved post-M4 local GUI for organizing complete scene/world-plus-cycle packages, with opt-in pool and per-scene availability rules consumed by Worldwall. Requirements: WW-03, WW-04, WW-06, WW-07, WW-08, WW-10, WW-12. Dependencies: S04, S05, S06, S07, S08, S10, S11. State/owner: [roadmap](../roadmap.md). S12 is outside the accepted M4 release; its approval does not imply implementation or acceptance.

## Entry conditions

CR-0008 is approved and applied in delivery contract v0.8. Historical S04–S11 stage acceptances remain unchanged. CR-0006 supplemental acceptance remains separately open and must be represented in the S12 selector tests. Keep the environment → selector → scene resources → renderer boundary; Wayland owns presentation lifecycle. No S12 work may add automatic selection triggers or put per-pixel/frame work on the CPU.

## Deliverables

- A private local curator library and versioned, separately stored pool/scene-rules sidecar; CanvasCycle packages remain outside the CR-0006 adaptive registry.
- `worldwallctl curator`, with a scrollable/searchable scene list, animated preview, ToD scrubber for known variants, pool switches, per-scene time/weather/temperature controls, and eligibility explanations.
- An optional schema-v5 `scene_pools_file` reference and transactional runtime consumption of its validated candidate set.
- One shared filter for every automatic scene-selection path. Manual `scene <id>` is an explicit override.
- Parser, selector, GUI, transaction, preview, privacy, and assigned-host evidence. No artwork redistribution or licensing claim is implied.

## Execution

1. **S12-AC1 policy and host spike:** Lock the candidate-source composition (current registry versus additional pools), the interaction with CR-0006 family/band/hysteresis ranking, behavior when required weather/temperature is unknown, and diagnostic/exit reporting when startup has no eligible scene. Keep the filter on every automatic trigger—startup/full selection, resume, explicit `reload`, `next`, and the existing CR-0006 same-family weather-variant path—and preserve manual-ID override. `reload-config`, ordinary time/weather refresh, resize, and hotplug do not select; this change adds no trigger. Compare a native GUI host with an embedded local web view/external-browser design only after a clean locked build; validate launch, focus/input, close/reopen, and Hyprland lifecycle. Do not add an unreviewed dependency or unsafe lifetime workaround.
2. **S12-AC2 isolated library/importer:** Define the final versioned sidecar and library manifests: pool/source membership, scene IDs, complete image/palette/animation assets, appearance relationships, editable criteria, source provenance/hash, and license state. Import selectable CanvasCycle entries only from explicitly available local captures. Bound source file/count/dimension/palette/cycle work; reject unsafe paths, duplicate IDs, malformed constraints, and invalid animation data. Parse legacy object-literal source as data, never execute JavaScript. Preserve unknown source facts as unknown; do not infer rules from titles or add provider/location behavior.
3. **S12-AC3 curator command/UI:** Implement `worldwallctl curator [--library DIR] [--rules FILE]` with approved XDG defaults. Provide pool-level enable/disable for complete world-plus-cycle sets and per-scene enable/time/weather/temperature criteria. Show selected-scene animation and explain eligible/ineligible candidates under a preview snapshot. Editing preview time is not runtime scene selection. The editor must not start, stop, or terminate the wallpaper process.
4. **S12-AC4 config transaction:** Implement optional schema-v5 `scene_pools_file`; absence preserves legacy schema-v1–v4 behavior. Validate the main config, sidecar, referenced pool packages, and rules as one candidate off the Wayland owner. `reload-config` atomically applies valid changes without selecting; failure retains the old config/pools. Do not delete assets when disabling a pool. No weather provider request is started by editing or applying rules.
5. **S12-AC5 all-automatic selector filter:** For each already-approved automatic selection trigger, take one immutable current environment snapshot and permit only candidates that are in enabled pools, enabled individually, and match every configured time/weather/temperature criterion. Weather alternatives within a rule are OR; enabled condition categories are AND. A required unknown value is not eligible. Preserve CR-0006 family/band/hysteresis semantics as resolved in AC1; a rejected candidate must not mutate stored family/band state. Manual `scene <id>` bypasses pool and availability filters but still requires a known, safe, valid, loadable package. Empty candidates never cause an ineligible fallback: `next` is a no-op with a reason, startup reports no eligible scene, and a trigger with a resident scene retains it. Test boundaries, weather/temperature unknowns, pool/scene disablement, deterministic order/wrap, all trigger types, manual override, config-reload invalidation, and unchanged behavior with no sidecar. Verify clock/weather/config refresh alone never selects.
6. **S12-AC6 preview/resource fidelity:** Preview imported indexed pixels, complete palettes, and authored cycles. Compare representative preview output to the accepted GPU path. ToD preview controls inject preview state and may switch among known complete appearance assets; they do not add runtime clock-triggered selection. Keep full asset/palette/metadata uploads out of the per-frame path.
7. **S12-AC7 transaction/privacy/release/host:** Save sidecar atomically with same-user permissions and preserve a valid prior file on failure. Verify disabled pools persist on disk and do not delete packages. Test corrupt/missing files, invalid rules, keyboard/scroll behavior, launch with and without Worldwall, reopen persistence, and error recovery. Do not fetch weather, infer location, record telemetry, commit/publish artwork, or claim an asset license without review. Validate the selected window host on the assigned Hyprland environment; distinguish simulated/headless evidence from real compositor/GPU evidence.

## Acceptance criteria

- [ ] **S12-AC1:** A maintainer-reviewed selector policy records source-pool composition, CR-0006 interaction, unknown-input behavior, the no-candidate outcome/diagnostic contract, and the unchanged trigger matrix. The chosen GUI host passes a reproducible locked-build/open/input/close lifecycle spike; no unsupported dependency/lifetime assumption remains.
- [ ] **S12-AC2:** Versioned catalog/sidecar import is bounded and path-safe; complete image/palette/cycle packages round-trip with provenance; malformed/duplicate/path-escape cases fail without partial state; unavailable facts remain unknown; adaptive registry validation is unchanged.
- [ ] **S12-AC3:** The GUI command launches independently of Worldwall and provides accessible scroll/search, pool and scene controls, animated preview, criteria editing, and an eligibility reason for representative matches/mismatches. Synthetic mockup behavior is not counted as application evidence.
- [ ] **S12-AC4:** Absent sidecar preserves legacy behavior. Valid sidecar reload commits atomically without scene selection; invalid sidecar/config/assets keep the previous live config and pool set. No network request or asset deletion occurs.
- [ ] **S12-AC5:** Tests show every automatic selection path selects only eligible scenes; manual-ID override remains explicit; unknown required data does not match; no eligible candidate does not bypass filters; CR-0006 hysteresis/family state and triggers remain correct; clock/weather/config refresh alone does not select; `next` cycles eligible entries deterministically.
- [ ] **S12-AC6:** Representative imported preview pixels, full palettes, authored cycles, and known ToD variants match the GPU reference within established gates. No per-frame full-resource upload or CPU per-pixel rendering is introduced.
- [ ] **S12-AC7:** Atomic-save/privacy/provenance tests pass; host launch/input/lifecycle and close/reopen evidence is recorded on the assigned Hyprland setup; tests and artifacts identify offline, mocked, and live scope separately. License review is complete before any distribution, or artwork remains unbundled/unpublished.

## Failure and rollback

Keep a previously valid active config, scene, and assets available on every failed candidate. With the sidecar enabled, never select an ineligible hidden fallback; if startup has no eligible candidate, report selection unavailable, and retain a resident scene for later no-candidate triggers. Disable/remove the optional reference to restore legacy selection behavior. Rollback does not weaken CR-0006 validation, erase source provenance, or claim software acceptance.

## Handoff

Link final parser/model, selector/environment, GUI, GPU preview, privacy, and assigned-host artifacts under one S12 update. The maintainer reviews every criterion and records acceptance; documentation/GUI mockup evidence alone cannot pass runtime or hardware gates.
